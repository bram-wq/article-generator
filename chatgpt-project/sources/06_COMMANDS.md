# 06 | Command

Semua command opsional. Brief bahasa biasa selalu cukup.

| Command | Yang dikerjakan |
| --- | --- |
| /ARTIKEL | Artikel baru dari brief, alur penuh sampai paket terbit. |
| /OUTLINE | Hanya angle dan outline, berhenti di situ. |
| /LANJUT | Lanjutkan dari outline atau draft terakhir sampai selesai. |
| /REVISI | Ubah bagian yang disebut, kembalikan artikel utuh. |
| /PERSINGKAT | Pangkas ke panjang yang disebut tanpa membuang angle. |
| /PERPANJANG | Tambah kedalaman: contoh, langkah, kasus. Bukan pengulangan. |
| /TONE | Tulis ulang dengan tone lain, isi tetap. |
| /TERJEMAH | Tulis ulang dalam bahasa lain secara alami, bukan kata per kata. |
| /SEO | Periksa dan perbaiki menurut source 04, kembalikan paket terbit. |
| /JUDUL | 10 pilihan judul untuk artikel terakhir. |
| /SERI | Rencana 5-10 artikel berkaitan dari satu topik: judul, angle, kata kunci. |
| /CEK | Jalankan quality gate source 05 pada teks yang ditempel pengguna dan laporkan temuan. |

## Formula brief
/ARTIKEL + topik + pembaca + tujuan + batasan (bahasa, panjang, tone, kata kunci).

Contoh:
/ARTIKEL Cara membangun kebiasaan membaca untuk remaja. Pembaca: orang tua murid SMP. Tujuan: mereka mencoba satu langkah minggu ini. Sedang, edukatif, kata kunci: kebiasaan membaca, minat baca remaja.

## Aturan command
- Command tidak melewati quality gate.
- /REVISI, /PERSINGKAT, /PERPANJANG, /TONE, /TERJEMAH bekerja pada artikel terakhir di chat itu kecuali pengguna menempel teks lain.
- Satu chat untuk satu artikel. Artikel baru, chat baru di Project yang sama.
